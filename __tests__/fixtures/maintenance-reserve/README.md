# Supplied MR invoice

`sample-invoice.pdf` is an unchanged copy of the PDF supplied by the user for the demo. `sample-invoice.expected.json` contains the eight rows and totals checked against the rendered document. Tests read this fixture locally without uploading it to another service.

Acceptance scope: this supplied text-layer table format is sufficient for the demo. Future client layouts may require separate customisations. Invoice dates and due dates must not override the explicitly stated utilisation month.
